# Participant: codex (AI agent)

## Understanding

The 0.7.1 publication exposed three related gaps. A scheduled cycle can be
missing while manual recovery succeeds; an old provider run can satisfy a
title-only watcher; and a repeated validation request can encounter an already
merged exact subject. Autonomy must distinguish those states and require
external, exact, idempotent receipts instead of relying on timing or prose.

## Execution plan

1. Commit this exact intent before changing normative or release artifacts.
2. Advance the standard, closed schema and checker from manifest v5 to v6.
3. Add heartbeat, correlation-bound post-boundary selection and authoritative
   effect-reconciliation contracts to the profile and examples.
4. Encode production evidence and failure behavior in architecture, logic,
   negative fixtures and regression tests.
5. Refresh exact profile and DSL bindings, run every deterministic gate, then
   publish only through the independent Validator App.
